### Notable upstream changes

**Channel start:**
- `channels.start` initiates a channel auth/connect flow. Params: `{channel: string}`. Returns opaque provider-specific payload.

**Diagnostics:**
- `diagnostics.stability` returns a gateway stability diagnostics snapshot. Accepts optional query params; returns opaque snapshot.

**Node pairing:**
- `node.pair.remove` removes a previously paired node by ID. Params: `{nodeId: string}`. Returns void.

**Talk realtime:**
- `talk.realtime.session` establishes a realtime voice session. Accepts opaque provider-specific params; returns opaque session payload.

**TTS personas:**
- `tts.personas` returns the list of available TTS personas with the active persona ID. No params. Returns `{active: string|null, personas: [{id, label}]}`.

**Update status:**
- `update.status` returns the current update restart sentinel. No params. Returns `{sentinel: string|null}`.

**VoiceWake routing:**
- `voicewake.routing.get` retrieves the voice wake routing config. No params. Returns `{config: object}`.
- `voicewake.routing.set` sets the voice wake routing config. Params: `{config: object}`. Returns void.
