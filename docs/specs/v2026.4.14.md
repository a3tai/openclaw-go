### Notable upstream changes

**Commands listing:**
- New `commands.list` method exposes available gateway commands filtered by agent, provider, scope, and arg inclusion options. Returns `{commands: CommandEntry[]}`.

**Exec approval listing:**
- New `exec.approval.list` method returns all currently pending exec approval records as `[]{id, request, createdAtMs, expiresAtMs}`.

**Message actions:**
- New `message.action` method dispatches a channel-specific action on a message (e.g., reactions, forwarding). Returns opaque channel response.

**Plugin approval listing:**
- New `plugin.approval.list` method returns all currently pending plugin approval records as `[]{id, request, createdAtMs, expiresAtMs}`.

**Session compaction checkpoints:**
- New `sessions.compaction.list` method lists compaction checkpoints for a session. Returns `{ok, key, checkpoints}`.
- New `sessions.compaction.get` method retrieves a specific checkpoint by ID. Returns `{ok, key, checkpoint}`.
- New `sessions.compaction.branch` method creates a new session branched from a checkpoint. Returns `{ok, sourceKey, key, sessionId, checkpoint, entry}`.
- New `sessions.compaction.restore` method restores a session in-place from a checkpoint. Returns `{ok, key, sessionId, checkpoint, entry}`.
