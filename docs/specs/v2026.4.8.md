### Notable upstream changes

**Exec and plugin approval listing:**
- New `exec.approval.list` method lists all pending exec approval requests. Returns an array of `{id, request, createdAtMs, expiresAtMs}` entries.
- New `plugin.approval.list` method lists all pending plugin approval requests. Same shape as `exec.approval.list`.

**Session compaction checkpoints:**
- New `sessions.compaction.list` method returns all compaction checkpoints for a session. Params: `{key}`. Returns `{ok, key, checkpoints[]}`.
- New `sessions.compaction.get` method retrieves a specific checkpoint by ID. Params: `{key, checkpointId}`. Returns `{ok, key, checkpoint}`.
- New `sessions.compaction.branch` creates a new session branched from a pre-compaction transcript snapshot. Params: `{key, checkpointId}`. Returns `{ok, sourceKey, key, sessionId, checkpoint, entry}`.
- New `sessions.compaction.restore` restores an existing session to a pre-compaction snapshot. Params: `{key, checkpointId}`. Returns `{ok, key, sessionId, checkpoint, entry}`.
