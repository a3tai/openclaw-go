# Upstream OpenClaw v2026.5.20 Sync Spec

## Summary

Sync `openclaw-go` with upstream OpenClaw `v2026.5.20`.

This release adds gateway/protocol coverage for 59 upstream RPC methods across diagnostics, doctor memory, channel lifecycle, TTS personas, plugin descriptors/actions, real-time talk sessions, model auth, generic tool invocation, task management, environments, artifacts, skill upload, sessions, node pairing, cron lookup, gateway restart, assistant media, web push, config file opening, and native hook invocation.

- Fixed `TTSSetProvider` to use the `MethodTTSSetProvider` constant instead of an inline string.
