### Notable upstream changes

**Dream diary diagnostics:**
- New `doctor.memory.dreamDiary` method exposes the agent's DREAMS.md dream diary file over the gateway. Returns `{agentId, found, path, content?, updatedAtMs?}`.

**Approval list endpoints:**
- New `exec.approval.list` returns all pending exec approval requests as an array of `{id, request, createdAtMs, expiresAtMs}`.
- New `plugin.approval.list` returns all pending plugin approval requests as an array of `{id, request, createdAtMs, expiresAtMs}`.

**Session compaction CRUD:**
- New `sessions.compaction.list` lists all compaction checkpoints for a session key. Returns `{ok, key, checkpoints[]}`.
- New `sessions.compaction.get` retrieves a single checkpoint by `checkpointId`. Returns `{ok, key, checkpoint}`.
- New `sessions.compaction.branch` creates a new session branched from a checkpoint snapshot. Returns `{ok, sourceKey, key, sessionId, checkpoint, entry}`.
- New `sessions.compaction.restore` restores an existing session to a checkpoint snapshot in-place. Returns `{ok, key, sessionId, checkpoint, entry}`.
