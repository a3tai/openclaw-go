### Notable upstream changes

**Dream diary maintenance methods:**
- New `doctor.memory.backfillDreamDiary` backfills the DREAMS.md dream diary from existing daily memory files. Returns `DoctorMemoryDreamActionResult` with `{agentId, action, path, found, scannedFiles, written, replaced}`.
- New `doctor.memory.resetDreamDiary` removes backfilled entries from the dream diary. Returns `DoctorMemoryDreamActionResult` with `{agentId, action, path, found, removedEntries}`.
- New `doctor.memory.resetGroundedShortTerm` removes grounded short-term memory candidates from the dreaming store. Returns `DoctorMemoryDreamActionResult` with `{agentId, action, removedShortTermEntries}`.
- New `doctor.memory.repairDreamingArtifacts` repairs corrupted dreaming artifacts (archiving bad files). Returns `DoctorMemoryDreamActionResult` with `{agentId, action, changed, archiveDir, archivedDreamsDiary, archivedSessionCorpus, archivedSessionIngestion, warnings}`.
- New `doctor.memory.dedupeDreamDiary` removes duplicate entries from the dream diary. Returns `DoctorMemoryDreamActionResult` with `{agentId, action, path, found, removedEntries, dedupedEntries, keptEntries}`.

**Model auth status:**
- New `models.authStatus` returns the authentication health status for all configured model providers. Returns `ModelsAuthStatusResult` with `{ts, providers[]}` where each provider has `{provider, displayName, status, expiry?, profiles[], usage?}`.
