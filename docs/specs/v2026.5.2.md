### Notable upstream changes

**Artifacts:**
- New `artifacts.list` method lists binary artifacts, optionally filtered by session. Returns an array of artifact summaries.
- New `artifacts.get` method retrieves a single artifact by ID.
- New `artifacts.download` method downloads the binary content of an artifact.

**Channels:**
- New `channels.start` method starts a channel connection for the given channel name.
- New `channels.stop` method stops a channel connection for the given channel name.

**Diagnostics:**
- New `diagnostics.stability` method returns gateway stability diagnostics (uptime, restart counts, etc.).

**Node pairing:**
- New `node.pair.remove` method removes an approved node pairing by request ID.

**Push (Web Push API):**
- New `push.web.subscribe` registers a Web Push subscription endpoint.
- New `push.web.unsubscribe` removes a Web Push subscription.
- New `push.web.test` sends a test Web Push notification.

**Sessions:**
- New `sessions.describe` returns a detailed description of a session (metadata, agent, config).
- New `sessions.cleanup` removes ephemeral session state for a completed session.

**Talk realtime:**
- New `talk.realtime.session` creates or retrieves a realtime voice session token.

**Tools:**
- New `tools.invoke` directly invokes a named tool outside a session context.

**TTS:**
- New `tts.personas` retrieves TTS persona definitions.

**Updates:**
- New `update.status` retrieves the current gateway update availability status.

**Voice wake routing:**
- New `voicewake.routing.get` retrieves the voice wake routing configuration.
- New `voicewake.routing.set` sets the voice wake routing configuration.

**Assistant media:**
- New `assistant.media.get` retrieves assistant-uploaded media by ID.
