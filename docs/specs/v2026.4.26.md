### Notable upstream changes

**New node pairing management:**
- New `node.pair.remove` method removes a paired node by `nodeId`. Returns void on success.

**New update status:**
- New `update.status` method returns the latest update restart sentinel. Result: `{sentinel}`.

**Backfilled channel and TTS methods:**
- `channels.start` initiates a channel connection. Params: `{channel, accountId?}`.
- `tts.personas` lists available TTS personas and the active one. Result: `{active, personas[]}`.
- `talk.realtime.session` creates a real-time voice session. Params: `{provider?, model?, voice?}`.

**Backfilled diagnostics and voice wake routing:**
- `diagnostics.stability` returns gateway stability diagnostics. Params: `{window?, limit?}`.
- `voicewake.routing.get` retrieves voice wake routing config. Returns raw config.
- `voicewake.routing.set` sets voice wake routing config. Params: `{config}`.

**Backfilled web push:**
- `push.web.subscribe` registers a web push subscription. Params: `{endpoint, keys}`.
- `push.web.test` sends a test web push notification. Params: `{title?, body?}`.
- `push.web.unsubscribe` removes a web push subscription. Params: `{endpoint}`.

**Backfilled assistant media:**
- `assistant.media.get` retrieves assistant media assets (from method-scopes.ts).
